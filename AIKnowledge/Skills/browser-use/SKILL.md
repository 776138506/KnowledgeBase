# Browser Use

此技能为 AI 助手提供网页浏览能力。

## 功能

- 访问和浏览网页
- 提取网页内容
- 执行网页交互操作
- 截图和页面分析
- 表单填写和提交
- 多标签页管理

## 使用方法

当用户需要浏览网站、提取网页内容或与网页交互时使用此技能。

## 核心能力

1. **页面导航**
   - 访问 URL
   - 前进/后退
   - 刷新页面
   - 历史记录管理

2. **内容提取**
   - 获取页面文本
   - 提取链接和图片
   - 解析表格和列表
   - 捕获结构化数据

3. **网页交互**
   - 点击元素
   - 填写表单
   - 下拉选择
   - 滚动页面
   - 键盘输入

4. **页面分析**
   - 元素定位
   - 页面结构分析
   - 等待条件满足
   - 弹窗处理

## 应用场景

- 信息检索和调研
- 网页数据抓取
- 自动化测试
- 在线表单填写
- 网站监控
- 跨页面导航任务

## 安全注意

- 仅访问可信网站
- 不保存敏感信息
- 遵守网站 robots.txt
- 尊重版权和使用条款
