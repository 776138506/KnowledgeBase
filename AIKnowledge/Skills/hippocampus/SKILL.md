# Hippocampus

## Overview

Hippocampus is a memory enhancement skill inspired by the brain's hippocampal region, which is responsible for memory formation and retrieval. This skill helps users improve memory recall, organize information, and enhance learning efficiency.

## Features

- **Memory Management**: Organize and categorize information for better retention
- **Spaced Repetition**: Implement scientifically-proven spaced repetition techniques
- **Knowledge Mapping**: Create connections between related concepts
- **Memory Recall**: Improve memory retrieval through targeted exercises
- **Learning Optimization**: Personalize learning strategies based on user patterns
- **Information Organization**: Structure information for better comprehension

## When to Use

Invoke this skill when:

- You need to remember important information
- You're studying for exams or learning new material
- You want to organize complex information
- You need to recall information from past conversations
- You're looking to improve your memory skills
- You want to create meaningful connections between concepts

## Usage

### Memory Management

```bash
# Create a memory entry
hippocampus add "[topic]" "[information]"

# Example
hippocampus add "JavaScript" "Closures are functions that have access to their own scope, the scope of the outer function, and the global scope."
```

### Spaced Repetition

```bash
# Schedule a memory review
hippocampus review

# Review specific topic
hippocampus review "[topic]"
```

### Knowledge Mapping

```bash
# Create a knowledge map
hippocampus map "[central concept]"

# Example
hippocampus map "Computer Science"
```

### Memory Recall

```bash
# Test memory recall
hippocampus test "[topic]"

# Get memory hints
hippocampus hint "[topic]"
```

## Memory Techniques

### Spaced Repetition System

A scientifically-proven technique that optimizes memory retention by reviewing information at increasing intervals:

1. **First review**: 24 hours after learning
2. **Second review**: 3 days after first review
3. **Third review**: 7 days after second review
4. **Fourth review**: 14 days after third review
5. **Fifth review**: 30 days after fourth review

### Mnemonic Devices

- **Acronyms**: Create words from the first letters of information
- **Visualization**: Associate information with mental images
- **Chunking**: Break information into smaller, manageable chunks
- **Method of Loci**: Associate information with specific locations
- **Rhymes and Songs**: Use rhythm to aid memory

### Active Recall

- **Practice retrieving information** rather than simply re-reading
- **Ask yourself questions** about the material
- **Teach the material** to someone else
- **Use flashcards** for active recall practice
- **Test yourself** regularly

## Best Practices

- **Regular Practice**: Consistent memory exercises improve retention
- **Active Engagement**: Engage with material actively rather than passively
- **Meaningful Connections**: Relate new information to existing knowledge
- **Proper Sleep**: Sleep is essential for memory consolidation
- **Healthy Lifestyle**: Exercise and nutrition support brain function
- **Stress Management**: High stress impairs memory formation

## Troubleshooting

### Common Memory Issues

- **Forgetting**: Normal part of memory process, use spaced repetition
- **Interference**: New information competing with old, use categorization
- **Retrieval Failure**: Inability to access stored information, use context cues
- **Absent-Mindedness**: Lack of attention during encoding, practice mindfulness

### Memory Optimization

- **Focused Attention**: Eliminate distractions when learning
- **Elaborative Rehearsal**: Connect new information to existing knowledge
- **Dual Coding**: Combine verbal and visual information
- **Metacognition**: Be aware of your own learning process
- **Environment Consistency**: Learn and recall in similar environments
