# GitHub 技能

此技能提供 GitHub 集成功能。

## 功能

- 浏览 GitHub 仓库
- 搜索代码
- 管理 Pull Requests
- 跟踪 Issues
- 查看提交历史
- 代码审查

## 使用方法

当用户需要与 GitHub 仓库交互或管理 GitHub 任务时使用此技能。

## 命令示例

- 浏览仓库文件
- 搜索特定代码
- 创建/查看 PR
- 管理 Issues
- 查看提交记录
