# Self-Improving Agent

此技能为 AI 助手提供自我改进能力。

## 功能

- 从用户反馈中学习
- 分析任务执行表现
- 识别改进机会
- 优化响应策略
- 跟踪性能指标
- 生成改进建议

## 使用方法

当用户希望改进 AI 助手性能或审查助手行为时使用此技能。

## 核心能力

1. **反馈学习**
   - 收集用户反馈
   - 分析成功/失败案例
   - 调整行为模式

2. **性能分析**
   - 跟踪任务完成率
   - 识别常见错误
   - 评估响应质量

3. **持续优化**
   - 识别最佳实践
   - 优化工作流程
   - 提升效率

## 应用场景

- 任务完成后进行复盘
- 用户提出改进建议时
- 定期性能审查
- 错误分析和修复
