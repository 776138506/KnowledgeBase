# Elite Long-Term Memory

此技能为 AI 助手提供长期记忆能力。

## 功能

- 存储重要信息和上下文
- 检索历史记忆
- 管理记忆优先级
- 压缩和摘要记忆
- 记忆关联和链接
- 遗忘机制管理

## 使用方法

当用户需要实现持久化记忆或访问历史上下文时使用此技能。

## 核心能力

1. **记忆存储**
   - 保存关键对话内容
   - 记录用户偏好
   - 存储任务上下文

2. **记忆检索**
   - 基于关键词搜索
   - 按时间线检索
   - 关联性查询

3. **记忆管理**
   - 优先级排序
   - 定期清理
   - 智能压缩

## 应用场景

- 跨会话记住用户偏好
- 长期项目上下文跟踪
- 个性化助手行为
- 历史决策参考
