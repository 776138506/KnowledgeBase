# [技能名称]

## 📁 创建规则

### 目录结构规范

**重要**: 创建新技能时，必须遵循以下目录结构：

```
AIKnowledge/Skills/
└── [SkillIdentifier]/          # 以技能英文名命名的文件夹
    └── SKILL.md                # 技能定义文件（固定名称）
```

### 创建步骤

#### 步骤 1：创建技能文件夹

1. 导航到 `AIKnowledge/Skills/` 目录
2. 使用技能的**英文标识名**创建文件夹
   - ✅ 正确示例：`MetaCognitiveSelfExpansion/`
   - ❌ 错误示例：`元认知与自我扩展/`、`meta-cognitive-self-expansion/`（应使用大驼峰）
   - ❌ 错误示例：`SkillIdentifier/`（不要使用占位符）

**命名规则**:
- 使用 **PascalCase**（大驼峰命名法）
- 首字母大写
- 单词间无空格，每个单词首字母大写
- 只包含字母、数字，不包含特殊字符

#### 步骤 2：创建 SKILL.md 文件

1. 在技能文件夹内创建 `SKILL.md` 文件
   - ✅ 正确示例：`SKILL.md`（全大写）
   - ❌ 错误示例：`Skill.md`、`skill.md`、`skill-definition.md`

2. 将本模板内容复制到 `SKILL.md` 中

3. 替换所有占位符 `[...]` 为实际内容

#### 步骤 3：验证目录结构

创建完成后，目录结构应如下：

```
AIKnowledge/Skills/
└── [SkillIdentifier]/
    └── SKILL.md
```

**示例**:
```
AIKnowledge/Skills/
├── MetaCognitiveSelfExpansion/
│   └── SKILL.md
├── CodeReviewer/
│   └── SKILL.md
└── DocumentationEngineer/
    └── SKILL.md
```

### 文件命名规范总结

| 项目 | 规范 | 示例 |
|------|------|------|
| 技能文件夹名 | PascalCase（大驼峰） | `MetaCognitiveSelfExpansion` |
| 技能定义文件 | 固定为 `SKILL.md`（全大写） | `SKILL.md` |
| 技能英文名 | PascalCase，无空格 | `MetaCognitiveSelfExpansion` |
| 技能中文名 | 清晰描述性中文 | `元认知与自我扩展` |
