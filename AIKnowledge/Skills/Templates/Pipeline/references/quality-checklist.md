# [产出物] 质量检查清单

> Pipeline 模式质量检查清单模板

## 使用说明

本检查清单用于在 Pipeline 流程的最后阶段验证产出物质量。

**使用方法**:
1. 逐项检查每个检查项
2. 标记通过（✅）、警告（⚠️）、失败（❌）
3. 失败项必须修复
4. 警告项评估后决定
5. 全部通过才能交付

## 检查结果处理

### 评分规则

**通过标准**:
- 完整性检查：100% 通过
- 准确性检查：100% 通过
- 安全检查：100% 通过
- 格式检查：≥ 95% 通过
- 性能检查：≥ 90% 通过
- 用户体验：≥ 85% 通过（如适用）

**严重程度定义**:

- **失败（❌）**: 必须修复，否则不能交付
  - 安全问题
  - 功能缺陷
  - 信息错误
  - 完整性缺失

- **警告（⚠️）**: 建议修复，影响质量
  - 格式问题
  - 性能优化空间
  - 文档不完整

- **通过（✅）**: 符合要求

5. **验证修复**: 验证修复效果
6. **重新检查**: 对修复项重新检查
7. **确认通过**: 所有项通过后才能交付
