# [审查对象] 检查清单

> Reviewer 模式检查清单模板

## 使用说明

本检查清单用于系统化审查 [审查对象]，确保质量和安全。

**使用方法**:
1. 逐条检查每个检查项
2. 标记符合（✅）、不符合（❌）、不适用（N/A）
3. 对不符合项记录详细信息
4. 按严重程度分类（error/warning/info）

## 审查评分规则

### 严重程度定义

- **error**（错误）: 必须修复，否则不能发布
  - 安全问题
  - 功能缺陷
  - 严重性能问题

- **warning**（警告）: 应该修复，影响质量
  - 代码规范违反
  - 潜在问题
  - 可维护性问题

- **info**（建议）: 建议改进，非必须
  - 最佳实践建议
  - 优化建议
  - 文档改进

### 评分计算

```python
def calculate_score(checklist_results):
    """
    计算审查评分
    """
    weights = {
        'code_quality': 0.30,
        'security': 0.25,
        'error_handling': 0.15,
        'performance': 0.15,
        'maintainability': 0.10
    }
    
    category_scores = {}
    for category, items in checklist_results.items():
        total = len(items)
        passed = sum(1 for item in items if item.status == 'pass')
        category_scores[category] = (passed / total) * 100 if total > 0 else 0
    
    overall_score = sum(
        category_scores[cat] * weight 
        for cat, weight in weights.items()
    )
    
    return overall_score, category_scores
```

### 评分等级

- **9-10 分**: 优秀，可直接发布
- **7-8 分**: 良好，修复警告后可发布
- **5-6 分**: 合格，需要修复部分问题
- **3-4 分**: 不合格，存在严重问题
- **1-2 分**: 差，需要全面重构
