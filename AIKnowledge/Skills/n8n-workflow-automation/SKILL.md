# n8n Workflow Automation

此技能提供 n8n 工作流自动化集成功能。

## 功能

- 创建和编辑 n8n 工作流
- 执行和测试工作流
- 管理工作流节点和连接
- 配置触发器和操作
- 集成第三方服务 API
- 导入/导出工作流

## 使用方法

当用户需要创建、编辑或管理 n8n 自动化工作流时使用此技能。

## 支持的操作

1. **工作流管理**
   - 创建新工作流
   - 导入/导出工作流 JSON
   - 激活/停用工作流

2. **节点操作**
   - 添加/删除节点
   - 配置节点参数
   - 连接节点

3. **执行控制**
   - 手动触发工作流
   - 查看执行历史
   - 调试工作流

## 常见用例

- 自动化数据同步
- API 集成
- 定时任务
-  webhook 处理
- 通知自动化
