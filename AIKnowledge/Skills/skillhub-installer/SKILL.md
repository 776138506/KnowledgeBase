# SkillHub 商店安装器

此技能用于安装和管理 SkillHub 商店。

## 安装步骤

1. 创建 `.trae/skills/` 目录结构
2. 安装 SkillHub 核心功能
3. 管理已安装的技能列表

## 使用方法

当用户需要安装 SkillHub 商店或管理技能时使用此技能。
