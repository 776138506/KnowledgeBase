# Find Skill

## Overview

Find Skill is a specialized tool that helps users discover and search for skills in the OpenClaw ecosystem. It provides a comprehensive way to explore available skills, filter by category, and find the right tools for specific tasks.

## Features

- **Skill Search**: Search for skills by name, description, or functionality
- **Category Filtering**: Browse skills by categories like development, productivity, research, etc.
- **Skill Details**: Get detailed information about specific skills
- **Installation Guidance**: Step-by-step instructions for installing skills
- **Recommendation Engine**: Suggest skills based on user needs and usage patterns
- **Skill Comparison**: Compare similar skills to find the best fit

## When to Use

Invoke this skill when:

- You need to find a specific skill for a task
- You want to explore available skills in a category
- You're looking for alternatives to existing skills
- You need installation guidance for a skill
- You want to discover new skills that might be useful

## Usage

### Basic Search

```bash
# Search for skills by keyword
find-skill search [keyword]

# Example
find-skill search "code review"
```

### Category Browsing

```bash
# List skills by category
find-skill browse [category]

# Example
find-skill browse development
```

### Skill Details

```bash
# Get details about a specific skill
find-skill info [skill-name]

# Example
find-skill info code-reviewer
```

### Installation Help

```bash
# Get installation instructions for a skill
find-skill install [skill-name]

# Example
find-skill install git-helper
```

## Troubleshooting

### Common Issues

- **Skill Not Found**: Try different keywords or check spelling
- **Installation Failures**: Ensure you have the latest OpenClaw version
- **Compatibility Issues**: Check skill requirements and OpenClaw version
- **Performance Problems**: Disable unused skills and optimize settings

### Error Messages

| Error | Solution |
|-------|----------|
| "Skill not available" | Check skill name and source availability |
| "Installation failed" | Verify network connection and permissions |
| "Compatibility error" | Update OpenClaw to the required version |
| "Search timeout" | Try with more specific keywords |
