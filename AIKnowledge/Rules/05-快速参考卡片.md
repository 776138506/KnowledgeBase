## 📝 代码规范速查

### 命名约定

| 类型 | 命名法 | 示例 |
|------|--------|------|
| 变量/函数 | camelCase | `userName`, `calculateTotal` |
| 类/组件 | PascalCase | `UserProfile`, `Button` |
| 常量 | UPPER_SNAKE_CASE | `MAX_COUNT`, `API_URL` |
| 文件 | kebab-case | `user-profile.js` |

### Git 提交类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `feat` | 新功能 | `feat(auth): 添加登录功能` |
| `fix` | Bug 修复 | `fix(login): 修复密码验证错误` |
| `docs` | 文档 | `docs(readme): 更新安装说明` |
| `refactor` | 重构 | `refactor(utils): 重构日期处理` |
| `test` | 测试 | `test(auth): 添加登录测试` |
| `chore` | 杂项 | `chore(deps): 更新依赖` |

## 📊 性能指标

### 前端目标

| 指标 | 目标值 |
|------|--------|
| FCP (首次内容绘制) | < 1.5s |
| LCP (最大内容绘制) | < 2.5s |
| CLS (累积布局偏移) | < 0.1 |
| FID (首次输入延迟) | < 100ms |

### 后端目标

| 指标 | 目标值 |
|------|--------|
| API 响应时间 (P95) | < 200ms |
| 数据库查询 | < 50ms |
| 错误率 | < 0.1% |

## 🐛 Debug 流程

```
1. 复现问题
   - 记录复现步骤
   - 确认问题现象

2. 定位原因
   - 查看错误日志
   - 检查相关代码
   - 使用调试工具

3. 修复验证
   - 实施修复
   - 测试验证
   - 回归测试

4. 记录总结
   - 更新文档
   - 添加测试
   - 分享经验
```

## 💡 常用命令

### Git

```bash
# 创建功能分支
git checkout -b feature/xxx

# 提交代码
git commit -m "feat(scope): description"

# 同步主分支
git fetch origin
git rebase origin/main

# 推送分支
git push -u origin feature/xxx
```

### NPM

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build

# 运行测试
npm test

# 代码检查
npm run lint
```
