# WF-03 系统设计 - 数据建模

> 设计系统的数据库结构（ER 图）

## 📋 目标

- 识别实体和属性
- 定义实体关系
- 设计数据库表结构

---

## 🗄️ 数据建模步骤

### 步骤 1：识别实体

从需求中提取名词：
- 用户（User）
- 订单（Order）
- 产品（Product）

### 步骤 2：识别属性

```
实体：用户
属性：
- 用户 ID（主键）
- 用户名
- 邮箱
- 密码哈希
- 创建时间
```

### 步骤 3：识别关系

**关系类型**：
- 1:1（一对一） - 用户 - 用户档案
- 1:N（一对多） - 用户 - 订单
- N:M（多对多） - 订单 - 产品（通过订单明细）

### 步骤 4：绘制 ER 图

**图形表示**：
- 实体：矩形
- 属性：椭圆
- 关系：菱形
- 基数标注：1, N, M

### 2. 数据库表结构设计

```sql
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_email (email)
);
```
