## cc-godmode (自编排开发)

**适用场景**：
- 完整的功能开发
- 复杂的代码重构
- 系统性优化

**使用示例**：
```
"使用 cc-godmode 创建一个完整的用户认证系统，包括：
- 登录/注册页面
- JWT token 管理
- 权限控制
- 密码重置功能"
```

## hippocampus (记忆管理)
