## 新功能开发

```markdown
## 任务：[功能名称]

### 背景
[描述业务背景和为什么需要这个功能]

### 目标
[清晰描述要实现的功能]

### 技术栈
- 框架：[React/Vue/Angular 等]
- 语言：[TypeScript/JavaScript]
- 其他：[相关库和工具]

### 功能要求
- [ ] 需求 1
- [ ] 需求 2
- [ ] 需求 3

### 非功能要求
- 性能要求
- 安全要求
- 兼容性要求

### 验收标准

- [ ] 功能测试通过
- [ ] 代码审查通过
- [ ] 单元测试覆盖≥80%
- [ ] **已调用 TDD 技能进行测试**
- [ ] 所有测试通过
- [ ] 文档完整

### 相关文件
- 设计稿：[链接]
- API 文档：[链接]
- 相关文件路径
```

```markdown
[描述应该发生什么]

### 实际行为
[描述实际发生了什么]

### 环境信息
- OS: [操作系统]
- Browser: [浏览器版本]
- Version: [应用版本]

### 错误日志
```
[粘贴错误日志或截图]
```

### 可能原因
[如果有猜测，可以说明]
```
