## 1. 迭代式开发

```
第一轮：创建基础结构
"创建一个用户列表组件的框架"

第二轮：添加功能
"添加搜索和过滤功能"

第三轮：优化完善
"添加虚拟滚动、错误边界和加载状态"
```

**要点**：
- 从简单开始
- 逐步增加功能
- 持续优化

---

## 2. 分而治之

```
❌ 不要："创建一个完整的电商网站"

✅ 推荐:
1. "创建商品列表组件"
2. "创建商品详情组件"
3. "创建购物车组件"
4. "创建结账流程"
```

**要点**：
- 大任务拆小
- 逐个击破
- 逐步集成

---

## 3. 及时反馈

```
✅ 好的反馈:
"这个实现很好，但是性能需要优化，
建议使用 useMemo 缓存计算结果"

❌ 不好的反馈:
"不行，重写"
```

**要点**：
- 具体明确
- 建设性意见
- 肯定优点

---

## 4. 渐进式复杂

```
第一步：简单实现
"先实现基本功能，不考虑边界情况"

第二步：添加错误处理
"现在添加错误处理和边界条件"

第三步：性能优化
"最后进行性能优化和代码重构"
```

**要点**：
- 先跑起来
- 再完善
- 最后优化

## 效率技巧

### 1. 使用快捷键

- `Ctrl+K` - 快速指令
- `Ctrl+L` - 聚焦聊天
- `Ctrl+Shift+P` - 命令面板

### 2. 批量处理

```
一次性说明所有需求：
"请帮我：
1. 创建用户登录组件
2. 添加表单验证
3. 编写单元测试
4. 更新文档"
```

### 3. 保存常用指令

创建指令模板文件，保存常用的指令格式。

### 4. 利用代码片段

```
看到好的实现，保存为代码片段：
"这个错误处理模式很好，记住它，
以后类似场景都使用这种方式"
```
