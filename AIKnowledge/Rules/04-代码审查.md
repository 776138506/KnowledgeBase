# AI 协作指南 - 代码审查

> AI 生成代码的审查流程

## 📋 审查清单

### 1. 功能正确性

- [ ] 代码实现符合需求
- [ ] 边界条件处理正确
- [ ] 错误处理完整
- [ ] 无逻辑错误

### 2. 代码质量

- [ ] 遵循项目代码规范
- [ ] 命名清晰易懂
- [ ] 函数职责单一
- [ ] 代码可复用性好

### 3. 性能

- [ ] 无明显的性能问题
- [ ] 使用了合适的算法和数据结构
- [ ] 避免不必要的计算
- [ ] 内存管理合理

### 4. 安全

- [ ] 输入验证完整
- [ ] 无 SQL 注入风险
- [ ] 无 XSS 漏洞
- [ ] 敏感信息处理正确

### 5. 测试

- [ ] 单元测试覆盖核心逻辑
- [ ] 测试用例包含边界情况
- [ ] 测试命名清晰
- [ ] 测试可独立运行

### 6. 文档

- [ ] 函数有必要的注释
- [ ] 复杂逻辑有说明
- [ ] API 文档完整
- [ ] 更新 CHANGELOG
