# 测试验证检查清单

## 必须验证（5 类）

### 1. 功能验证
- [ ] 功能正确性
- [ ] 边界条件
- [ ] 异常处理
- [ ] 性能表现

### 2. 输入输出验证
- [ ] 输入验证
- [ ] 输出验证
- [ ] 类型安全
- [ ] 数据一致性

### 3. 文档规范
- [ ] 代码注释
- [ ] API 文档
- [ ] 开发日志

### 4. 测试覆盖率
- [ ] 覆盖率 ≥ 80%
- [ ] 分支覆盖
- [ ] 边界条件测试

### 5. 最终检查
- [ ] 所有测试通过
- [ ] 无 ESLint 错误
- [ ] 无 TypeScript 错误
- [ ] 开发日志已记录

## 验证命令

```bash
npm run lint
npm run type-check
npm run test
npm run test:coverage
npm run build
```
