## 2. 立即上手

### 步骤 1：了解核心原则

**必须遵守**: TDD 测试驱动开发

```
1. RED     - 先写测试，测试应该失败
2. GREEN   - 写最少代码让测试通过
3. REFACTOR - 重构代码保持测试通过
```

参考文档：
- [01-测试验证规范.md](01-测试验证规范.md)
- [02-tdd-guide.md](02-tdd-guide.md)

### 步骤 2：掌握工作流程

8 阶段开发流程：

```
需求分析 → 功能规格 → 系统设计 → 接口实现 → 测试 → 文档 → 评审 → 部署运维
```

参考文档：
- [00-概述.md](00-概述.md)
- [00-工作流程总览.md](00-工作流程总览.md)
