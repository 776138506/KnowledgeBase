# AI 协作指南 - 常见问题

> 常见问题解答

## Q: 如何让 AI 理解我的项目结构？

**A**: 提供项目结构信息：

```
我的项目结构如下：
src/
  ├── components/     # UI 组件
  ├── pages/         # 页面组件
  ├── services/      # API 服务
  ├── utils/         # 工具函数
  ├── hooks/         # 自定义 hooks
  └── types/         # TypeScript 类型

请在这个结构下添加一个新的用户管理模块。
```

---

## Q: AI 生成的代码不符合项目风格怎么办？

**A**: 提供代码示例：

```
请参考以下代码风格来实现：

[粘贴项目中的示例代码]

按照这个风格创建一个新的 XX 组件。
```

---

## Q: 如何让 AI 记住之前的讨论？

**A**: 使用记忆技能或提供上下文：

```
根据我们之前讨论的用户认证方案（使用 JWT），
现在实现登录页面的表单验证部分。
```

---

## Q: 如何验证 AI 生成的代码是否正确？

**A**: 要求 AI 提供验证方法：

```
实现这个功能后，请提供：
1. 完整的测试用例
2. 手动测试步骤
3. 预期输出示例
4. 可能的边界情况
```

---

## Q: 如何处理 AI 生成的错误代码？

**A**: 提供详细错误信息：

```
代码运行时出现以下错误：

[错误信息]

问题出现在：[文件路径：行号]

请分析原因并修复。
```
