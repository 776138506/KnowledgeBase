# WF-04 接口实现 - 接口定义

> 遵循"接口优先"原则，先编写接口

## 📋 目标

- 遵循"接口优先"原则
- 先编写接口定义
- 后实现具体逻辑

---

## 🔄 工作流程

```
接口定义 → 接口评审 → 实现类编写 → 单元测试 → 代码审查 → 集成
```

---

## 📝 接口定义原则

1. 接口保持稳定，不频繁变更
2. 接口方法职责单一
3. 使用合适的参数类型
4. 明确异常抛出

---

## 💻 接口代码示例

```java
// 第一步：定义接口
public interface IUserService {
    User createUser(UserDTO dto) throws UserAlreadyExistsException;
    Optional<User> getUserById(Long id);
    Page<User> listUsers(int page, int size);
    User updateUser(Long id, UserDTO dto) throws UserNotFoundException;
    void deleteUser(Long id) throws UserNotFoundException;
}

// 第二步：定义数据模型
@Data
@Builder
public class User {
    private Long id;
    private String username;
    private String email;
    private String passwordHash;
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}

// 第三步：定义 DTO
@Data
public class UserDTO {
    @NotBlank(message = "用户名不能为空")
    private String username;
    
    @NotBlank(message = "邮箱不能为空")
    @Email(message = "邮箱格式不正确")
    private String email;
    
    @NotBlank(message = "密码不能为空")
    @Size(min = 8, message = "密码长度至少 8 位")
    private String password;
}
```
