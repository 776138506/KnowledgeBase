# WF-03 系统设计 - 接口设计

> 设计系统的接口（接口图）

## 📋 目标

- 定义服务层接口
- 设计 API 接口
- 制定版本管理策略

---

## 🔌 接口设计步骤

### 步骤 1：识别接口

**服务层接口**：
- IUserService
- IOrderService
- IProductService

**API 接口**：
- /api/users
- /api/orders
- /api/products

**外部接口**：
- IPaymentGateway
- IEmailService

### 步骤 2：定义接口契约

```java
public interface IUserService {
    /**
     * 创建新用户
     */
    User createUser(UserDTO dto) throws UserAlreadyExistsException;
    
    /**
     * 根据 ID 获取用户
     */
    User getUserById(Long id) throws UserNotFoundException;
    
    /**
     * 更新用户信息
     */
    User updateUser(Long id, UserDTO dto);
    
    /**
     * 删除用户
     */
    void deleteUser(Long id);
}
```

### 步骤 3：API 接口设计（RESTful）

使用 OpenAPI/Swagger 格式定义

### 步骤 4：版本管理策略

```
- URL 版本：/api/v1/users, /api/v2/users
- 请求头版本：Accept: application/vnd.api.v1+json
- 参数版本：/api/users?version=1
```
