# 工作流程概述

## 8 阶段流程

```
需求 → 功能规格 → 系统设计 → 接口实现 → 测试 → 文档 → 评审 → 部署运维
```

## 核心原则

1. **需求驱动** - 用例图驱动需求
2. **设计先行** - ER 图、类图、接口图
3. **接口优先** - 先定义接口契约
4. **测试伴随** - 每个阶段有验证
5. **文档持续** - 文档逐步完善
6. **质量门禁** - 每阶段有评审

## 阶段说明

| 阶段   | 产出           |
| :--- | ------------ |
| 需求分析 | 需求规格说明书      |
| 功能规格 | 用例规约文档       |
| 系统设计 | ER 图、类图、设计文档 |
| 接口实现 | 接口代码、单元测试    |
| 测试   | 测试用例、测试报告    |
| 文档   | API 文档、用户手册  |
| 评审   | 评审报告         |
| 部署运维 | 部署文档、监控配置    |

**详细文档**: workflow-index.md
