# MyKnowledge Obsidian 知识库

个人知识库项目，基于 Obsidian 构建。

## 📁 目录结构

```
MyKnowkedge/
├── AIKnowledge/              # AI 知识库
│   ├── Context/             # 上下文知识
│   ├── Memory/              # 记忆库
│   ├── Rules/               # 规则配置
│   ├── Skills/              # 技能库
│   └── SubAgent/            # 子代理配置
│
└── MyKnowledge/             # 个人知识库主目录
```

## 📚 知识库说明

### AIKnowledge
存放 AI 相关的知识和配置，包含：
- **Context**: 上下文相关的知识文档
- **Memory**: 长期记忆和重要信息
- **Rules**: 规则和最佳实践文档
- **Skills**: 技能和能力文档
- **SubAgent**: 子代理相关配置

### MyKnowledge
个人主要知识库，用于存放日常笔记和知识文档。
